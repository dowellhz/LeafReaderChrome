LeafReader Chrome Privacy Policy

Last updated: August 17, 2026

Local storage

LeafReader Chrome stores captured webpages, annotations, vocabulary, reading preferences, and AI conversation history locally in the browser.

AI features

Selected text and relevant reading context are sent only when the reader explicitly invokes an AI action, and only to the AI provider configured in Settings. LeafReader Chrome does not operate a backend that receives this reading data.

API keys remain in extension-local storage and are excluded from backups by default.

Offline dictionary

The bundled offline dictionary is queried locally and makes no network request.

Website access

The extension requests access to HTTP and HTTPS pages solely to provide its selection toolbar, original-page markers, and reader-mode capture on webpages the reader chooses to use.
